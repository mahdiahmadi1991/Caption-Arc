# Product Use Cases

## Real-Time Translation During Meetings

- user joins a supported browser meeting
- captions are captured and translated in the overlay
- user can tune model/language and translation prompt behavior

## Post-Meeting Review

- session is saved in local archive
- user searches/filter sessions in meeting history
- user exports transcript and generates summaries by profile

## Multi-Device Continuity

- user enables Google Drive App Data and/or OneDrive App Folder sync
- archive data is mirrored and merged across devices
- device-only secrets remain local
