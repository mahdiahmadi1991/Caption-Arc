# Execution Plans

This folder stores task-specific execution plans governed by:

- [../execution-plans.md](../execution-plans.md)

## Layout

- [active/README.md](./active/README.md): plans for ongoing work
- [completed/README.md](./completed/README.md): completed or superseded plans kept for traceability

## Naming

Use:

- `YYYY-MM-DD-short-kebab-case-title.md`

Example:

- `2026-04-06-overlay-runtime-hardening.md`
